# مختبر عماد الافتراضي — ImadLab

محاكاة ثلاثية الأبعاد لتجارب مختبر الأحياء، يجرّبها الطالب والباحث قبل دخول المختبر الحقيقي.
إعداد البروفيسور عماد محمد فرحان.

## التشغيل

الموقع ثابت بالكامل، ويعمل على GitHub Pages دون أي بناء:

- `index.html` قائمة التجارب.
- `lab.html?exp=<id>` مشغّل التجربة.

للتجربة محليًا: `python3 -m http.server` ثم افتح `http://localhost:8000`.

## البنية

| الملف | الوظيفة |
|---|---|
| `js/catalog.js` | فهرس التجارب والأقسام وحالة كل تجربة (مجانية / قيد البناء / مميّزة) وإعدادات الموقع |
| `js/scene.js` | المشهد الثلاثي الأبعاد العام: الغرفة والمنضدة والإضاءة والكاميرا والالتقاط |
| `js/engine.js` | محرك الخطوات: المساعدة نور، الأسئلة، الدرجات، دفتر المختبر، التقرير |
| `js/scope-view.js` | منظر العدسة العينية: الضبط، الإضاءة، الحجاب القزحي، مسطرة القياس |
| `js/specimen-onion.js` | توليد نسيج بشرة البصل ورسمه واختبار النقر على أجزائه |
| `js/models/` | نماذج المجهر وأدوات المنضدة |
| `js/experiments/` | ملف لكل تجربة |
| `vendor/three.min.js` | مكتبة Three.js r187 |

## خطة البناء

1. ✅ المحرك وواجهة المختبر وتجربة المجهر وخلايا البصل.
2. التجارب المجانية الأربع الباقية: الكشف عن المواد الغذائية، أثر الحرارة في الإنزيم، الأسموزية في البطاطا، تشريح قلب الخروف.
3. نظام الاشتراك (Supabase): رمز تفعيل لجهاز أو جهازين، ولوحة إدارة لتوليد الرموز.
4. التجارب المميّزة دفعة بعد دفعة.
